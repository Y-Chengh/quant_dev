[项目常驻要求 —— 出自本仓库 AGENTS.md「验证要求」，由 UserPromptSubmit hook 每轮注入]

本仓库维护者的长期要求：本轮若改动了代码，在完成验证后新建一个独立 sub-agent
对本次改动做 code review，review 通过前不要提交。

- 验证按 AGENTS.md「验证要求」一节执行。
- review 范围只含本次改动，重点看正确性、未来数据泄漏、接口兼容性、边界条件、测试覆盖。
- 发现问题先修复、重新验证，再新建 sub-agent 复审；通过前不得提交。
- 通过后只提交属于本任务的变更块，不带入工作区中原有的无关改动。
- 交付说明列出 review 结论、验证命令、提交摘要与 commit hash。

本轮为纯问答或纯查阅，且工作区不存在本会话产生的、尚未 review 的改动时，不适用本要求。
但只要本轮要执行提交，无论本轮是否动手改过文件，都必须先确认待提交内容已通过 review。
